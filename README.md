# 📱 연락처 앱 (Phone Number App)

이 프로젝트는 **JuiceStand** 라이브러리를 활용하여 만든 **연락처 관리 앱**입니다. 사용자는 앱을 통해 연락처를 **추가**, **삭제**, **수정**, **검색**할 수 있습니다.

## 🚀 기능

- **📋 연락처 추가**: 새로운 연락처를 간편하게 추가할 수 있습니다.
- **✏️ 연락처 수정**: 기존 연락처 정보를 손쉽게 수정할 수 있습니다.
- **🗑️ 연락처 삭제**: 필요 없는 연락처를 삭제하여 목록을 정리할 수 있습니다.
- **🔍 연락처 검색**: 연락처 이름으로 빠르게 검색하여 원하는 연락처를 찾을 수 있습니다.

## 🛠️ 기술 스택

- **Frontend**: JavaScript, zustnad
- **Backend**: 없음 (클라이언트 사이드 앱)
- **UI/UX**: 간단한 UI, 직관적인 인터페이스
